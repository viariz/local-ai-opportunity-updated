public/ — published website with blurred teasers for the three unreleased chapters.
full/   — complete, unblurred website with all chapter content and media.

This combined ZIP contains private content. Send it only to someone who should
receive the full essay. It does not contain the live site's password or session keys.

LOCAL PREVIEW (Python 3 required)
Extract the ZIP, open a terminal in this folder, then run one of:

    python3 preview.py public
    python3 preview.py full

Open http://localhost:8000/introduction in your browser.
Stop with Ctrl+C before switching editions, or choose --port 8001.

HOSTING
The public/ folder can be published as a static site supporting _redirects.
The full/ folder is an offline export, not password-protected by itself.
The hosted full edition is protected at https://thesis.deepshard.org.
Do not upload full/ to an unprotected public host.
